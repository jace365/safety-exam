# 산업안전기사 실기 작업형 암기 음성 앱

실기 작업형 요약 자료를 40개 페이지로 묶어, 한국어 음성(TTS)으로 들으며 암기하는 모바일용 웹앱입니다.

## 기능
- 🔊 항목별 음성 읽기 (반복 1·2·3·5회, 속도 조절)
- 자동 다음 페이지 재생
- 가리기 모드: 소리만 듣고 떠올린 뒤 탭하여 확인
- 좌우 스와이프 페이지 이동, 마지막 페이지 기억
- 재생 중 화면 꺼짐 방지 (지원 브라우저)

## 사용법
`index.html` 한 파일로 동작합니다. 서버나 빌드가 필요 없습니다.

### GitHub Pages로 배포
1. 이 폴더의 파일을 저장소에 올립니다.
2. 저장소 **Settings → Pages**에서 Branch를 `main` / `(root)`로 선택하고 저장합니다.
3. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속합니다.
4. 휴대폰에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

## 내용 수정
`index.html`의 `var D=` 아래 데이터를 고치면 됩니다. 한 줄이 한 페이지이며 형식은 다음과 같습니다.

```
제목|항목1;항목2;항목3
```
